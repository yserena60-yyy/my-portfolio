# Yuhan (Serena) Yang · Digital Humanities Portfolio

An interactive portfolio of my research and creative work in digital humanities, designed in the style of an old printed book.

**Live site:** https://yserena60-yyy.github.io/my-portfolio/

## What's inside

- **Principal works**: *Uncertainty in Motion* (MA dissertation, UCC), *Vincent: A Life Behind the Name* and *Vestige*
- **Three threads**: Uncertainty and the archive, Culture in space and interaction, and AI as collaborator and subject. Each thread opens as a book spread gathering its works.
- **About**: my path into digital humanities, with a map of the museum cities that shaped it

## How it's built

The whole site is a single self-contained `index.html` with HTML, CSS and vanilla JavaScript. Images and the map are embedded, so there is no build step and nothing to install. Open the file in a browser to view it locally.

The travel map was drawn with d3-geo from Natural Earth and world-atlas data and saved as inline SVG.
