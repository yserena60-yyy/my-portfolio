PROJECT 01 / SPATIAL HUMANITIES · HERITAGE METADATA
Heritage Metadata Visualization Spatial Network Analysis Archival Uncertainty Modelling

Evidential Cartography of Eurasian Porcelain Networks

Uncertainty-Encoded Spatial Trade Mapping

Architected a spatial network visualization prototype tracing the multi-century circulation of East Asian export porcelain across early modern Eurasian trade corridors. Critically, the system encodes evidentiary uncertainty directly into cartographic variables — line opacity, stroke weight, and timeline position — rather than smoothing archival gaps into false continuity. Normalized and structured legacy metadata from the British Museum and Rijksmuseum collections, translating unstructured archival text into machine-readable spatial records. Deployed QGIS for topological data modelling and Mapbox Studio for dynamic rendering.

QGIS Mapbox Studio Wikidata SPARQL Mapbox GL JS GeoJSON Python
PROJECT 02 / CROSS-PLATFORM · HERITAGE HCI
Cultural Heritage HCI Spatial Navigation Community Knowledge Architecture

CultureMap — Heritage Exploration System

Cross-Platform Gamified Spatial Learning

Engineered a cross-platform mobile and web application that transforms the physical encounter with cultural landmarks into a structured, data-rich educational experience. Aggregates heritage metadata in real-time via Wikidata SPARQL and Wikipedia REST API, surfacing temporal site histories and curatorial narratives. Architected a PostgreSQL-backed community annotation layer via Supabase. Deployed OSRM-powered multi-modal turn-by-turn navigation with voice prompts. The gamified passport-stamp acquisition model directly operationalizes informal public education through embodied spatial movement.

Flutter Mapbox GL Supabase Wikidata SPARQL OSRM API SQLite

PROJECT 03 / SPATIAL HUMANITIES · AI VISION HCI
Spatial Humanities AI Vision-Based HCI Immersive Heritage Interpretation

Mythic Arcanum — AI-Mediated Spatial Humanities

Irish Mythological Cycles · Computer Vision Interaction

Developed an immersive, browser-deployed spatial humanities application mapping the four epochal cycles of Irish mythology across a real-time Three.js celestial environment. Synthesized touchless AI interaction via Google MediaPipe's computer vision hand-tracking pipeline, enabling gesture-driven navigation without physical peripherals — a design directly applicable to accessible, hands-free museum installation contexts. Deployed IMAX-style cinematic video theater with GSAP camera trajectory animations to deliver structured mythological narrative as a spatially sequenced educational arc.

Three.js r160 WebGL / GLSL MediaPipe Hands GSAP Web Audio API
